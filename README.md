# siwa-feiyu

丝袜、渔网与裙摆模拟技术快照，以及 DeepSeek 大肥鱼核心 3D 模型。

## 内容

- `Assets/Scripts/Runtime/Unity/Visual/Gameplay/Stocking/`：布料约束、角色动作、手部抓取与裙摆演示逻辑。
- `Assets/Tests/StockingDemo/`：演示场景、Shader、材质和测试资源。
- `.claude/tools/stocking-demo/`、`.claude/jobs/swml-v1.md`：演示工具和技术方案记录。
- `references/DeepSeek大肥鱼形象素材_2026-11-11/00_模型文件/`：两套 VRM 模型、一份 Blender 源文件，以及来源与授权说明。

视频、历史帧、预览图和其他候选素材仍保留在本机文件夹中，不纳入本次提交。仙侠道原有角色、贴图、业务代码和工程配置均未移动。

这是代码与资源快照，尚未整理成可独立运行的新 Unity 工程；场景中的部分资源引用仍依赖原项目。后续会话再替换角色并调整效果。
