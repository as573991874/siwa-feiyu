# 撕袜大作战 · 肥鱼快跑

竖屏第一人称追逐小游戏（three.js）。肥鱼在海边栈道上一路往前跑，你在后面追：按住冲刺追上去，松开后看准她后甩的那条腿，用对应的手拽住、撕破。限时内破碎比例达标过关，一共六关。

```bash
npm install
```

```bash
npm run dev
```

`npm run dev` 会先把模型从 `references/` 复制到 `public/models/`（该目录不入库）。录像用 `node record.mjs` 生成到 `preview/`（不入库）。

## 操作

| | 键盘 | 触屏 |
| --- | --- | --- |
| 冲刺（按住） | 空格 / Shift / W / ↑ | 底部中间按钮 |
| 左手（按住拽） | A / ← / J | 底部左按钮 |
| 右手（按住拽） | D / → / L | 底部右按钮 |
| 暂停 / 选关 | Esc | 右上角 ⏸ |

- **冲刺**：耗体力，快速拉近距离；镜头升高、视野变广，能看到肥鱼全身。体力见底要缓一下。
- **近身**：松开冲刺且距离够近时，镜头压低贴到腿边。她左右腿交替后甩，哪条腿甩到身后（按钮和腿边缘会亮），就按哪只手拽住；**按住**直到撕开，提前松手会弹回去。
- 时机不对会抓空并断连击；左右手交替撕破有「左右开弓」加成，洞更大、拽得更快。
- 近身后她会慢慢甩开你，出了范围就得再冲刺。
- 破碎比例按**身后能看到的那半圈丝袜**上破洞 + 抽丝的面积算。

## 关卡

| 关 | 丝袜 | 跑姿 | 时限 / 目标 | 设计意图 |
| --- | --- | --- | --- | --- |
| ① 海边晨跑 | 超薄黑丝 | 慢跑 | 40s / 40% | 教学：窗口宽、一拽就破 |
| ② 蹦蹦跳跳 | 白丝 | 蹦跳跑 | 40s / 48% | 起伏大、节奏变了 |
| ③ 渔网蛇行 | 渔网 | 蛇形走位 | 40s / 52% | 横向晃动，窗口变窄 |
| ④ 夕阳散步 | 超薄肉丝 | 散步 | 22s / 45% | 喘息关：很好撕，但时间短 |
| ⑤ 樱粉冲刺 | 加厚樱粉 | 全力冲刺 | 45s / 60% | 厚、快、甩得开，要频繁冲刺 |
| ⑥ 终极肥鱼 | 加厚黑丝 | 多动 | 48s / 66% | 决战：蛇形 + 蹦跳 + 最窄窗口 |

用自动玩家（`?bot`，反应间隔按真人估）测得的通关用时：①②③⑤⑥ 约 7.5 / 11 / 12 / 17 / 19 秒；④ 在目标还是 55% 时测得 13 秒，之后调低到 45%、没有重测。真人用时没有实测。

## 代码

| 文件 | 内容 |
| --- | --- |
| `src/main.js` | 关卡表、追逐距离 / 体力、双手状态机、双机位相机与奔跑晃动、入场动画、界面、自动玩家 |
| `src/girl.js` | 肥鱼的程序化奔跑循环（六种跑姿）、回头挑衅、被撕时的反应、表情 |

| `src/stocking.js` | 丝袜：半分辨率 PBD 布料 + 全分辨率破洞 / 抽丝 / 褶皱贴图 |
| `src/legfit.js` `src/shaders.js` `src/skirt.js` `src/audio.js` | 腿部网格拟合、着色器、百褶裙、合成音效 |

## 已知取舍

- 撕裂是「拽满触发 + 程序化生长」，下手点由程序在背面挑破损最少的位置，不需要瞄准。
- 肥鱼原地跑，靠地面和栏杆滚动表现前进；脚没有做贴地 IK。
- 近身视角会把尾巴和背后的丝带藏起来（否则会挡住整条腿）。
- 录像是无头浏览器软件渲染逐帧截的，没有声音。
