# 撕袜大作战 · 肥鱼快跑

竖屏第一人称追逐小游戏（three.js）。肥鱼在一条望不到头的长房间里一路往前跑，你在后面追：按住冲刺追上去，松开后看准她后甩的那条腿，用对应的手拽住、撕破。攒满气力会触发「大成功」慢放拼力气。限时内破碎比例达标过关，一共六关，场景在客厅、树屋、卧室之间轮换。

```bash
npm install
```

```bash
npm run dev
```

`npm run dev` 会先把模型从 `references/` 复制到 `public/models/`（该目录不入库）。录像用 `node record.mjs` 生成到 `preview/`（不入库）。

## 操作

| | 键盘 | 触屏 |
| --- | --- | --- |
| 冲刺（按住） | 空格 / Shift / W / ↑ | 底部中间按钮 |
| 左手（按住拽） | A / ← / J | 底部左按钮 |
| 右手（按住拽） | D / → / L | 底部右按钮 |
| 暂停 / 选关 | Esc | 右上角 ⏸ |

- **冲刺**：耗体力，快速拉近距离；镜头升高、视野变广，能看到肥鱼全身。体力见底要缓一下。
- **近身**：松开冲刺且距离够近时，镜头压低贴到腿边，她的步子会放慢。左腿对应青色、右腿对应粉色：哪条腿到了时机，那条腿边缘就发同色光、底部同色按钮亮起，按对应的手拽住；**按住**直到撕开，提前松手会弹回去。按错手会提示「错手」，按早了会提示「早了」。
- 时机不对会抓空并断连击；左右手交替撕破有「左右开弓」加成，洞更大、拽得更快。
- 近身后她会慢慢甩开你，出了范围就得再冲刺。
- 破碎比例按**身后能看到的那半圈丝袜**上破洞 + 抽丝的面积算，「大成功」每次额外 +14%。

### 大成功（气力槽）

每撕破一次攒一点气力，连击攒得更快。攒满后自动进入慢放：她坐到地板上、向后撑着，把伸过来的左腿往回收，你右手捏住小腿上的丝袜往外拽、左手按在膝盖外侧。

- **狂点**任意按键或屏幕往回拉；她会一阵一阵地往回拽，点慢了条就往她那边走。
- 越绷越紧时镜头绕到侧面贴近小腿，能看清布面被拉起、变薄、一道道抽丝的过程。
- 拉满：沿小腿整片崩开，她一屁股坐地上气鼓鼓地认输，然后爬起来接着跑。
- 被拽回去：布面弹回，她做个鬼脸跑掉，气力保留三成。
- 拼力气期间关卡计时暂停。

### 胜负演出

- **过关**：她坐在地板上，双腿朝你伸过来、膝盖微屈并拢、脚背绷直，一手在身后撑地、一手搭在膝上，气鼓鼓地说「哼，不跟你玩了！」。大成功撕开后也会这样坐一下再起身接着跑。
- **超时**：你力竭趴在地上，第一人称抬头，一只手还朝她的鞋尖够着，她侧身低头、半眯着眼斜你一眼：「就这？」

## 关卡

| 关 | 场景 | 丝袜 | 跑姿 | 时限 / 目标 | 设计意图 |
| --- | --- | --- | --- | --- | --- |
| ① 午后客厅 | 客厅 · 暖阳 | 超薄黑丝 | 慢跑 | 30s / 42% | 教学：窗口宽、一拽就破 |
| ② 清晨树屋 | 树屋 · 晨光 | 白丝 | 蹦跳跑 | 30s / 50% | 起伏大、节奏变了 |
| ③ 黄昏卧室 | 卧室 · 粉紫 | 渔网 | 蛇形走位 | 32s / 55% | 横向晃动，窗口变窄 |
| ④ 烛光客厅 | 客厅 · 烛光 | 超薄肉丝 | 散步 | 18s / 48% | 喘息关：很好撕，但时间短 |
| ⑤ 萤火树屋 | 树屋 · 夜 | 加厚樱粉 | 全力冲刺 | 36s / 62% | 厚、快、甩得开，要频繁冲刺 |
| ⑥ 霓虹卧室 | 卧室 · 霓虹 | 加厚黑丝 | 多动 | 40s / 70% | 决战：蛇形 + 蹦跳 + 最窄窗口 |

用自动玩家（`node timing.mjs`，反应间隔按真人估）重测的结果（时限收紧前测的，收紧不影响它的用时）：

| 关 | 计时消耗 | 含拼力气的实际时长 | 大成功次数 |
| --- | --- | --- | --- |
| ① | 6.0s | 16s | 1 |
| ② | 9.0s | 20s | 1 |
| ③ | 9.4s | 29s | 2 |
| ④ | 8.5s | 18s | 1 |
| ⑤ | 13.8s | 26s | 1 |
| ⑥ | 16.8s | 33s | 2（其中 1 次被拽回去） |

时限约为自动玩家用时的 2~5 倍。真人用时没有实测。进度过半还没触发过大成功时会直接送一次，保证每关至少有一次。

## 已知取舍

- 撕裂是「拽满触发 + 程序化生长」，下手点由程序在背面挑破损最少的位置，不需要瞄准。
- 肥鱼原地跑，靠地板、墙面和家具滚动表现前进；脚没有做贴地 IK。
- 家具是圆角体和基础几何体拼的，带灯晕和光斑，但不是美术建模的资产。
- 坐地时双脚全程用 IK 摆在地板上方（包括坐下的过渡过程）。
- 被拉起的丝袜尖端直接跟着糙汉拳头里攥布的那一点（拇指尖与食指中节的中点）走，手在哪布就在哪。
- 拼力气时糙汉的左手够不到膝盖外侧时会停在画面下方。
- 糙汉的身体整体放在镜头后方并限制了探身幅度，正常视角下只看得到手臂。
- 鲸鱼尾巴和背后垂下的丝带全程隐藏，只留短裙和丝袜。
- 录像是无头浏览器软件渲染逐帧截的，没有声音。
